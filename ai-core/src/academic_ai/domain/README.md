# AI domain

Nơi đặt evidence/citation/locator, logical slide/table/figure, candidate group và policy học thuật thuần. Chỉ dùng kiểu và logic độc lập framework.

Giữ source ID/version/hash, physical page và bbox khi có; nguồn HTML dùng locator tương ứng, không ép thành PDF. `observed`, `derived`, `unknown` phải phân biệt. Quyền nguồn và review state không được model tự thay đổi.

Chưa có domain implementation. Không đặt parser SDK, SQL, HTTP request hoặc cấu hình model ở đây.

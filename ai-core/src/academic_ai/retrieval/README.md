# Retrieval

Nơi đặt chính sách hybrid search, candidate-group normalization/dedup, fusion/reranking orchestration và context packing theo evidence groups. Client BM25/vector/reranker nằm trong infrastructure.

Phải giữ scope qua nhánh text/visual và parent/neighbor/source fetch. Đo coverage sau packing, không chỉ trước packing. Generated descriptions chỉ hỗ trợ tìm kiếm, không thay nguồn citation.

Chưa chọn embedding/vector database/reranker; xem [thiết kế indexing](../../../../docs/architecture/02-indexing-retrieval-design.md).

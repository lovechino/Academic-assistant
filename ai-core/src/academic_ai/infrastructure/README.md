# AI infrastructure

Adapter cho native PDF parser, OCR, render, model provider, embedding, reranker, search index và source access. Implement ports của application/domain, không sở hữu chính sách nghiệp vụ.

Giữ cấu hình, version, timeout, chi phí và lỗi có cấu trúc tại boundary. Không tải/cài model hoặc gửi nguồn cách ly ra dịch vụ ngoài chỉ để hoàn thiện skeleton. Chưa có adapter sản phẩm.

# Versioned prompts

Nơi dành cho prompt/template của router và ba trợ lý. Khi thêm prompt cần ghi mục tiêu, input/output contract, version và bộ eval liên quan.

Không chứa keys, tài liệu nguồn chưa được phép hoặc đáp án test kín. Hiện chưa có prompt runtime; không dùng nội dung README làm prompt mặc định.

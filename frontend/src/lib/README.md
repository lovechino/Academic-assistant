# Frontend support code

API transport/stream handling, DTO validation/mapping và utilities phục vụ UI. Không biến `lib/` thành nơi chứa nghiệp vụ của backend hoặc AI core.

API client phải xử lý lỗi/abort và nguồn bị thu hồi; dữ liệu scope của client không phải quyền đã xác thực. Chưa có client được triển khai.

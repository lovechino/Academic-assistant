# Product features

Khi triển khai, chia theo bốn trải nghiệm: Academic Assistant, Learning Assistant, Knowledge Hub và workspace review học liệu. Mỗi feature sở hữu UI/state/hooks của chính nó.

Không tạo cả bốn feature skeleton sâu khi chưa làm chức năng. Rule học thuật và quyền thực nằm phía server; frontend chỉ biểu diễn trạng thái qua public contract.
